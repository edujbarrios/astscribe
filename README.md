# ASTScribe

> **Evidence-backed scientific explanations for ML notebooks, without LLMs.**

ASTScribe is an open-source, lightweight static semantic analysis library for Python machine-learning notebooks. It is designed to transform ML code into traceable scientific explanations using Python's AST, framework-specific semantic rules, and deterministic pattern recognition.

**No LLMs. No API keys. No code execution. No telemetry.**

ASTScribe is fully open source from its first commit and is designed to remain independent of proprietary AI services.

## Status

ASTScribe is currently under active early development. The first implementation focuses on PyTorch and Jupyter/IPython workflows.
